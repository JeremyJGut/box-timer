# box-timer
Workout timer for a CrossFit box: coaches set up workouts on desktop, the timer runs full screen on a phone. TypeScript + Firebase.

## Development

Requires Node 20+ and the Firebase CLI (npm install -g firebase-tools).

    npm install
    npm run dev       # http://localhost:5173
    npm run build     # type-check (strict) + production build
    npm run deploy    # build + deploy hosting and Firestore rules

Live: https://box-timer-yaqbot.web.app
